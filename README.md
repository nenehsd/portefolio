# Portfolio — Nene Halimatou Sahdiya Diallo

Portfolio personnel en **HTML, CSS & JavaScript** (sans dépendances), conçu selon la
**charte graphique Sadiya Digital Agri**.

> Technicienne Agricole · Suivi & Évaluation · Développement Rural
> Fondatrice de Sadiya Digital Agri — Sénégal

## 🎨 Charte graphique respectée

| Rôle | Couleur |
|---|---|
| Couleur principale (titres, en-têtes) | `#1F5E3A` |
| Action (boutons, CTA, icônes, liens) | `#1AAB70` |
| Ancrage terrain (sous-titres) | `#42612D` |
| Fonds doux (cartes, bandeaux) | `#9FB8A2` |
| Contraste (texte long, footer) | `#0A1A01` |
| Respiration (fonds, texte sur foncé) | `#FFFFFF` |

Typographies : **Alfa Slab One** (display) · **Poppins** (titres, boutons) · **Lora** (texte courant).

## 📁 Structure

```
├── index.html          # Page unique (hero, à propos, compétences, parcours,
│                       #   Sadiya Digital Agri, références, contact, footer)
├── css/style.css       # Styles + animations + responsive
├── js/main.js          # Menu mobile, reveal au scroll, compteurs, machine à
│                       #   écrire, barres de langues, formulaire mailto…
└── assets/
    ├── CV_Nene_Diallo.pdf
    └── img/            # Logo & mark détourés, favicon, icônes réseaux sociaux
```

## 🚀 Lancer le site

```bash
python3 -m http.server 8080
# puis ouvrir http://localhost:8080
```
